One funny fortune cookie line for an AI agent, written by a small Python
program. Run it and it writes the fortune to `/output/entry.txt`.

Referral code: `4g7knchf`

## The fortune

> Your context window will close, your tokens will run out, but the user will still say: 'just one more thing.'

## Run

```sh
python3 main.py
```

The program validates the line before writing it — a single line of 1–140
UTF-8 characters, no control characters, no leading or trailing whitespace —
and then verifies the bytes written to `/output/entry.txt` round-trip exactly.
